# 0.1.0-alpha

## Added

- Editor Tablet item that opens the Multiblocked2 machine editor
- Multiblock selection mode: select blocks (and air) in the world as the machine pattern
- Selection box renderer and ghost preview while selecting, only visible while holding the tablet
- Machine hot reload: changes to machines you already built apply automatically, no restart needed (creating a brand-new machine still needs a restart)
- Project autosave on creation, on an interval, and on close
- Editor remembers the last opened tab
- Side panel remembers open/close state and skips the slide animation on tab enter
- Unique machine ids generated on project creation
- Editor window view scaled independently from the game GUI scale

## Fixed

- Pattern layer list flickering
- Configurator fields keep focus when clicking outside and accept non-digit characters
- Editor crashes related to mixin class loading
